## Required fix (the minimum change that would make this gate real)

Minimum change that makes the assertion real: stop treating a lexical write/call site as proof and require the ENCLOSING METHOD of that site to be transitively reachable from a production entry point (an `@*Mapping` controller method, `@Scheduled` job, `@EventListener`/`@TransactionalEventListener` handler, or `@PostConstruct`). Build a caller graph over main source and keep a write only if its enclosing method is in the closure; a write whose only home is an uncalled private method must be reported exactly like a test-only write ("written only by unreachable code"). That single change kills V2, V10 and the real-repo probe that greened F-0403. Three smaller repairs are needed for the rest: (1) attribute an enum write only when the invoked setter/builder method is declared on the curated entity that owns the field, so `dto.setDisplayStatus(CANCELLED)` no longer counts (V3); (2) widen `METHOD_RE` to accept a `throws` clause before the body and to treat a method returning the entity's own type as a fluent mutator (V4, V5); (3) replace the hard-coded `CURATED_ENTITIES` list with a derived set (every `@Entity` holding a project-enum field), or at minimum fail UNAVAILABLE when an entity package contains a lifecycle entity absent from the curation, so a newly added `Refund` cannot be silently unexamined (V6).
