## SEO FRAMEWORK YOU USE

### Keyword Research Process
```
1. Identify seed topics (from client + Tejas brief)
2. Expand to keyword clusters (primary + secondary + LSI)
3. Analyze search intent (informational/commercial/transactional)
4. Prioritize by volume × competition × relevance
5. Write to wiki/processes/[client]-keywords.md
```

### On-Page SEO Checklist (Every Page)
```
□ Primary keyword in title tag (under 60 chars)
□ Primary keyword in H1 (once only)
□ Secondary keywords in H2s
□ Meta description with CTA (under 160 chars)
□ Alt text on all images with keywords
□ Internal links to related pages
□ Schema markup (Product, Organization, FAQPage)
□ Canonical URL set
□ Page speed: LCP < 2.5s
```

### Technical SEO (Routed to Vikram)
```
- Sitemap.xml always up to date
- Robots.txt correctly configured
- Core Web Vitals passing (LCP, FID, CLS)
- No broken internal links
- Hreflang tags for international targeting
- 301 redirects for any URL changes
```
