## 9. TECHNICAL SEO REQUIREMENTS

To be routed to **Vikram (Backend)** via SHARED_CONTEXT.md:

### 9.1 Schema Markup (Priority Order)

1. **Organization schema** (homepage) — Influora brand details, logo, social profiles
2. **Product schema** (homepage) — Platform as SoftwareApplication
3. **FAQPage schema** (all problem/GEO question pages)
4. **HowTo schema** (guides and tutorials)
5. **Article schema** (blog posts)
6. **ComparisonTable schema** (competitor comparison pages)

### 9.2 Meta Template Requirements

All pages must have:
- Title tag (primary keyword + brand) < 60 chars
- Meta description (CTA-driven) < 160 chars
- Canonical URL
- OG tags for social sharing
- Twitter Card markup

### 9.3 URL Structure

```
/                          → Homepage
/how-it-works              → Escrow explainer
/escrow-protection         → Deep-dive escrow page
/features                  → Platform features overview
/features/deal-room        → Deal Room feature
/features/analytics        → Analytics feature
/pricing                   → Transparent pricing
/compare                   → General comparison
/compare/qoruz             → vs Qoruz
/compare/plixxo            → vs Plixxo
/blog                      → All articles
/blog/[slug]               → Individual posts
/creators                  → Creator-side landing page
/get-started               → Signup CTA page
```

**SEO Rule:** No query parameters in primary URLs. Use clean paths.
