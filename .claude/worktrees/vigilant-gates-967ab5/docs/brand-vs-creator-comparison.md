# Brand vs Creator Flow - Complete Comparison

## Overview

Both Brand and Creator have parallel workflows for deal management, but from opposite perspectives. This document shows the complete flow from both sides.

---

## Deal Lifecycle

### From Brand's Perspective

```
1. DISCOVER & APPROACH
   ├─ Brand finds creator in Discover page
   ├─ Clicks "Send Proposal"
   └─ Opens creator's Deal Room with proposal form

2. BRAND SENDS PROPOSAL (in Deal Room)
   ├─ Multi-step form: Deliverables → Budget → Timeline → Usage Rights → Terms
   ├─ Shows cost breakdown: Creator Payout + Platform Fee + GST
   ├─ Sends proposal → Appears as card in chat

3. NEGOTIATION (Chat Timeline)
   ├─ Creator sees proposal card
   ├─ Creator can: Accept / Counter / Decline
   ├─ If counter: New counter-proposal card appears
   ├─ Back and forth until agreement

4. BOTH AGREE
   ├─ Contract auto-generated from accepted proposal
   ├─ Contract card appears in timeline
   ├─ Brand can sign immediately

5. BRAND SIGNS
   ├─ "Sign Now" button on contract
   ├─ Signature recorded, status: "Brand Signed, Awaiting Creator"
   ├─ Escrow funds locked (₹X amount)

6. CREATOR SIGNS
   ├─ Creator sees contract card
   ├─ "Sign Now" button
   ├─ After signing: Status "Active"

7. CREATOR SUBMITS DELIVERABLES
   ├─ Creator submits file + caption
   ├─ Deliverable card appears in timeline
   ├─ Brand reviews

8. BRAND REVIEWS
   ├─ "Approve" → Payment released to escrow
   ├─ "Request Changes" → Revision (max 2)

9. APPROVAL & PAYMENT
   ├─ Brand approves final deliverable
   ├─ Payment ₹X released from escrow to creator wallet
   ├─ Deal marked complete

10. RATING
    ├─ Brand rates creator (quality, communication, timeliness)
    └─ Creator rates brand
```

### From Creator's Perspective

```
1. RECEIVE OPPORTUNITY
   ├─ Creator sees incoming proposal in Inbox
   ├─ Shows: Amount, deliverables, deadline, earnings breakdown
   └─ Expires in: 2 days

2. REVIEW PROPOSAL
   ├─ "View Details" → Opens in Deal Room
   ├─ See brand's proposal card in chat
   ├─ See earnings breakdown: Gross - Fee - GST - TDS = Net

3. RESPONSE OPTIONS
   ├─ Accept → Creates deal, moves to Deal Room
   ├─ Counter → Opens counter-proposal form
   ├─ Decline → Rejects opportunity
   └─ Message → Ask questions without deciding

4. COUNTER-PROPOSAL (if needed)
   ├─ 5-step form: Deliverables → Budget → Timeline → Terms → Message
   ├─ Propose different amount
   ├─ See updated earnings in real-time
   ├─ Send counter → Appears in timeline

5. NEGOTIATION (Chat Timeline)
   ├─ Creator sees brand's responses
   ├─ Can counter again if needed
   ├─ Both keep going until agreement

6. ACCEPT FINAL TERMS
   ├─ Creator accepts (or brand accepts creator's counter)
   ├─ Contract auto-generated
   ├─ Contract card appears in timeline

7. CREATOR SIGNS CONTRACT
   ├─ Reviews contract PDF
   ├─ "Sign Now" button
   ├─ Signature recorded
   ├─ If brand not signed yet: "Awaiting Brand Signature"
   ├─ If brand signed: Status "Active"

8. SUBMIT DELIVERABLES
   ├─ Upload file(s) with caption
   ├─ Deliverable card appears in timeline
   ├─ Creator waits for brand review

9. WAIT FOR APPROVAL
   ├─ Brand reviews deliverable
   ├─ If approved → "Revision 1/2" prompt
   ├─ Creator updates and resubmits

10. FINAL APPROVAL & PAYMENT
    ├─ Brand approves after 2 revisions max
    ├─ Payment ₹X released to creator wallet
    ├─ Notification: "₹X received in your wallet"

11. RATE BRAND
    ├─ Rating modal appears after completion
    ├─ Rate: Quality, Communication, Timeliness
    └─ Add optional comment
```

## Side-by-Side Comparison

### Navigation

| Brand | Creator |
|-------|---------|
| Home (Dashboard) | Inbox (Opportunities) |
| Campaigns (List/Detail/Create) | Active (Collaborations) |
| Discover Creators | Deal Room (Chat/Contracts) |
| Deal Room (Chat) | Wallet (Earnings) |
| Wallet (Payments) | Profile (Public) |
| Settings | Settings |

### Core Workflows

| Workflow | Brand | Creator |
|----------|-------|---------|
| **Initiation** | Brand finds creator → Send Proposal | Creator sees opportunity → View Details |
| **Proposal** | Brand fills 5-step form with cost breakdown | Creator sees proposal card in Deal Room |
| **Counter** | Brand can counter a bid | Creator fills 5-step counter form |
| **Agreement** | Brand accepts counter-proposal | Creator accepts brand's proposal |
| **Contract** | Auto-generated when both agree | Auto-generated when both agree |
| **Signing** | Brand signs first (can sign anytime) | Creator signs after brand (if brand already signed) |
| **Deliverables** | Brand specifies & reviews | Creator submits & revises |
| **Approval** | Brand approves/requests revisions | Creator submits/revises based on feedback |
| **Payment** | Brand pays from wallet balance | Creator receives to wallet after approval |
| **Rating** | Brand rates creator after completion | Creator rates brand after completion |

### Deal Room Experience

| Aspect | Brand Deal Room | Creator Deal Room |
|--------|-----------------|-------------------|
| **Left Panel** | Deal list with status | Deal list with status |
| **Right Panel** | Chat timeline | Chat timeline |
| **Cards** | Proposals (sent), Counters (received), Contracts, Deliverables | Proposals (received), Counters (sent), Contracts, Deliverables |
| **Actions** | Send Proposal, Accept/Counter bid, Sign Contract, Review Deliverables | View Proposal, Counter, Sign Contract, Submit Deliverables |
| **Messages** | Brand-initiated messages | Both-way messages |
| **Payments** | Release/Escrow | Receive/Wallet |

### Proposal Forms

| Stage | Brand | Creator |
|-------|-------|---------|
| **Step 1** | Select deliverables | Review deliverables |
| **Step 2** | Set budget (brand decides) | Counter with amount (shows earnings) |
| **Step 3** | Timeline/Deadline | Review/Request timeline change |
| **Step 4** | Usage rights + Add-ons | Accept/Decline usage rights |
| **Step 5** | Custom clauses + Final review | Review terms + Add message |

### Earnings Display

| Context | Brand Shows | Creator Shows |
|---------|------------|---------------|
| **Proposal** | "You will pay ₹X total" | "You will earn ₹Y net" |
| **Counter** | "New bid: ₹X" | "You propose ₹X (earn ₹Y net)" |
| **Contract** | "Value: ₹X" | "Value: ₹X (Your earnings: ₹Y)" |
| **Wallet** | Payments made (outgoing) | Payments received (incoming) |
| **Deliverable Approval** | "₹X released to escrow" | "₹X received in wallet" |

**Earnings Breakdown Formula for Creator:**
```
Proposed Amount:        ₹X
Platform Fee (10%):    -₹(X × 0.10)
GST on Fee (18%):      -₹(Fee × 0.18)
TDS (10%):             -₹(X × 0.10)
─────────────────────────────
Your Earnings:          ₹(X - Fee - GST - TDS)
```

### Wallet

| Brand Wallet | Creator Wallet |
|--------------|----------------|
| Shows balance (available funds) | Shows balance (earned funds) |
| Transaction history: Payments made (outgoing) | Transaction history: Earnings received (incoming) |
| Add funds (UPI, Cards, Net Banking) | Request withdrawal (Bank, UPI) |
| Shows fees paid | Shows TDS breakdown |
| Pay creators | Receive from brands |

### Profile

| Brand Profile | Creator Profile |
|---------------|-----------------|
| Company info, logo, description | Personal info, handle, bio |
| Team members + roles | Social links (Instagram, YouTube, etc.) |
| Verification badge | Follower counts |
| Rating from creators | Rating from brands |
| Completed campaigns | Completed deals |
| Available: edit | Available: edit + portfolio upload |

## Campaign vs Direct Proposal

### Brand's Campaign Creation
```
Brand creates campaign with:
├─ Fixed deliverables
├─ Budget range (e.g., ₹20K-₹40K)
├─ Deadline
├─ Usage rights (predefined)
└─ Open for creator bids

Multiple creators can bid
Brand selects winner
```

### Creator's Campaign Bid
```
Creator sees campaign in Inbox
└─ Campaign details (required deliverables, budget range)
    ├─ Fill bid form:
    │  ├─ Propose rate (within range)
    │  ├─ Write pitch
    │  ├─ Attach portfolio samples
    │  └─ Send
    │
    └─ Bid status: Pending → Shortlisted → Accepted/Declined
```

## Data Flow Example

### Full Deal Lifecycle with Data

```
Day 1: Brand sends proposal
├─ BrandProposal created
├─ Amount: ₹50,000
├─ Deliverables: 2 Reels, 3 Stories
├─ Creator sees in Inbox (CreatorProposal.status = "new")
└─ Deal Room shows proposal card

Day 2: Creator counters
├─ CreatorCounter created
├─ Counter Amount: ₹50,000
├─ Brand sees in Deal Room chat
├─ Brand accepts

Day 3: Agreement reached
├─ Proposal status: "accepted"
├─ Contract auto-generated
├─ ContractData.amount = ₹50,000
├─ Both see contract card in Deal Room
└─ Contract.status = "generated"

Day 4: Both sign
├─ Brand signs: Contract.brandSignature recorded
├─ Creator signs: Contract.creatorSignature recorded
├─ Escrow ₹50,000 locked
├─ Contract.status = "active"
└─ Deliverables tracking begins

Days 5-10: Creator submits deliverables
├─ Reel 1 submitted → Brand approves
├─ Stories submitted → Brand requests changes
├─ Creator revises → Brand approves
├─ Payment ₹25,000 released for each approval

Day 11: Deal complete
├─ All deliverables approved
├─ Total paid: ₹50,000
├─ Creator receives net: ₹50K - ₹5K fee - ₹900 GST - ₹5K TDS = ₹39,100
├─ Both rate each other
└─ Deal.status = "completed"
```
