7. "Green tests, red reality" pattern

This RC repeatedly shows the pattern this team has previously flagged as systemic risk: a mocked/H2 test suite is green while real MySQL or a real external gateway behaves differently.

  • AffiliateSettlementJobTest PASS, but real MySQL rejects the ENUM value the job writes (EV-011).
  • WalletServiceTest PASS, but the real VARCHAR(64) column overflows on real withdrawal idempotency keys (EV-014).
  • 3621/3621 Java unit tests green, but the application cannot boot at all (EV-001) — none load a full Spring context.
  • BrandDeliverableServiceTest 32/32 PASS, but the tested "approve" flow does not actually release money in production (EV-019) — unit tests never assert the cross-service linkage.
